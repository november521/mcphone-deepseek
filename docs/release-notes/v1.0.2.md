# MCphone DeepSeek v1.0.2

**把 DeepSeek 装进 MCphone 的手机里** —— 一个照着网页版做的对话 App：流式逐字输出、可折叠的深度思考、Markdown 排版、多段对话，全部画在那块 120×176 的屏幕里。这是 MCphone 的**第一个附属模组**。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · **只装客户端**
**前置：** [MCphone](https://github.com/november521/mcphone) 1.8.18 或更高 —— 硬前置，没有它这个模组一个类都跑不起来
**需要自备：** 一个 DeepSeek API Key（<https://platform.deepseek.com>），或任何 OpenAI 兼容接口

**服务端不用装。** 请求由你自己的客户端直连 DeepSeek，Minecraft 服务器不参与、也看不到任何一个字。

> **为什么第一个版本是 1.0.2 而不是 1.0.0？** 1.0.0 和 1.0.1 都只在本地存在过，从没发布。版本号没有回拨——发出来的就是 1.0.2 这个数，与 jar 里、模组列表里写的完全一致。下面「这个数之前发生过什么」一节列了那两次改了些什么。

---

## 💬 对话

照着网页版做的：用户的话是右对齐的蓝气泡，助手的话铺满整行没有气泡；深度思考收在「▾ 已深度思考（用时 6 秒）」一行里，点一下展开或收起；空页面正中是那只鲸鱼和一句「我是 DeepSeek，很高兴见到你！」。

**逐字出字，不是等它说完再一次性刷出来。** 生成过程中圆形发送键变成停止键，点了就真的把连接断掉。

**Markdown 是解析过的，不是把符号原样画出来**：粗体、斜体、列表、围栏代码块、行内代码。流式输出中途那个还没闭合的围栏也当代码块画——不然代码会先以正文的样子闪一下再跳成代码块。

没照抄网页版的三样，各有原因：联网搜索（API 没这个参数，做一个点不动的开关比没有更糟）、上传附件（手机里没有文件系统可以挑文件）、左边栏（120 像素宽塞不下，改成 ≡ 进去的一页）。

## 🗂 多段对话

`＋` 开新的，`≡` 进列表挑旧的。对话记录存在 `config/mcphone_deepseek/conversations.json`，**不按存档分**——你和 DeepSeek 之间的事和世界、和服务器都没关系，换个服务器还该在。

## ⚙️ 设置

Key 填好之后模型列表会自动从 `GET /models` 拉一次，点一下就换。

**「服务地址」可以填任何 OpenAI 兼容的接口**（硅基流动、Ollama、自建网关等）。多数服务要求把 `/v1` 带上，例如 `https://api.siliconflow.cn/v1`。填错时报错会明说是 404，而不是含糊的"网络错误"；余额不够会认成"余额不足"，也不是笼统的网络错误。

**两个默认值是为了不让你收到意外账单：**

- **单次回复上限 2048 token。** 模型一口气能吐 38 万，而这块屏幕只有 120 像素宽——真吐那么多，你滚不到底，账单却是真的。设成 0 才是不限。
- **带上几条上下文 20 条。** 带得越多越懂前文，每次也越贵。设成 0 就是每次只发当前这一句。

关掉「深度思考」也能省一截，简单问题不必让它想。

## 🔒 关于你的 Key

存在 `config/mcphone_deepseek/config.json`，**明文**。这一点不含糊：模组没有系统钥匙串可用，自己"加密"再把密钥放在同一台机器上，只是让人误以为它安全。

实际做的是另外三件事——界面上只显示末四位、日志里一个字都不写、除了你自己填的那个服务地址之外不发去任何地方。多人游戏里每个人用自己的 Key、花自己的钱，服主和同服玩家都看不到你的内容。

Key 和对话**刻意分成两个文件**：对话记录可以随手拷给别人看、可以整个删掉重来，Key 不行；而且对话文件写得勤得多，它写坏了不该把 Key 一起带走。

## 给服主

**什么都不用做。** 这个模组是纯客户端的（`mods.toml` 里写的是 `side="CLIENT"`），服务端装不装都一样，装了也不会多收一个包。玩家自己那台机器上的事。

它不新增任何服务端配置项，不动任何存档格式，不加任何网络协议。

## 给整合包作者

前置是 MCphone 1.8.18 或更高，**版本下限就是编译对着的那个版本**，没有放宽。附属宣称支持一个从没编译验证过的本体旧版，只会把 `NoSuchMethodError` 留给玩家。

模组不自带 API Key，玩家必须自己填一个才能用。空 Key 时 App 正常出现在主屏，点进去是引导去设置的空页面，不会崩也不会报错。
